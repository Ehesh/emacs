#+TITLE: E6's Emacs — Org & Notes Starter Guide
#+STARTUP: overview
#+OPTIONS: toc:2

A hands-on guide to *actually using* this Emacs. Open it any time with =SPC n G=.
Work through it in order; do the little exercises. Everything here works in this
config as shipped.

* First: how to move and type (meow)
:PROPERTIES:
:CUSTOM_ID: meow
:END:

Buffers start in *NORMAL* state — letters are commands, not text.

- =i= → *insert* (now you type normally).  =ESC= → back to normal.
- Move: =h j k l= (left/down/up/right), =w=/=b= (word forward/back),
  =e= (next word), =x= (select whole line).
- Select then act: =x= (line) then =s= (kill) or =y= (copy) or =c= (change).
- Undo: =u=.  Search: =/= is the leader search; in normal state =n= repeats.
- *Panic button:* =M-x meow-global-mode= turns modal editing off entirely.
- Full layout: =M-x meow-cheatsheet=.

*Exercise:* put the cursor on this line, press =x= (selects it), then =y=
(copies), move down, press =p= (paste).

* The leader (SPC) — your command palette
:PROPERTIES:
:CUSTOM_ID: leader
:END:

In normal state press =SPC=, wait, and which-key shows the options.

| Key       | Does                                             |
|-----------+--------------------------------------------------|
| =SPC SPC= | Run any command (M-x)                             |
| =SPC .=   | Find file                                        |
| =SPC ,=   | Switch buffer (consult)                          |
| =SPC /=   | Search this buffer (consult-line)                |
| =SPC c=   | Capture a note (see below)                       |
| =SPC \vert= | Pipe region/buffer to an AI CLI                |
| =SPC b/f/w= | Buffers / Files / Windows menus                |
| =SPC g=   | Git (Magit)                                      |
| =SPC l=   | Launch & convert (exports + services)            |
| =SPC n=   | Notes menu (capture, inbox, agenda, guide, elfeed) |
| =SPC r=   | Research menu (citations, PDF/noter, IPA, spell) |
| =SPC m=   | Email (himalaya)                                 |
| =SPC s=   | Search menu (line, ripgrep, grep, imenu…)        |
| =SPC t=   | Toggles (wrap, numbers, theme, olivetti, read-aloud) |
| =SPC h=   | Help (describe function/variable/key/mode)       |

* Org basics
:PROPERTIES:
:CUSTOM_ID: org-basics
:END:

** Headings and folding
=*=, =**=, =***= make headings. =TAB= folds/unfolds a heading;
=S-TAB= cycles the whole document.

** TODOs
Type =* TODO Something=. Press =S-<right>/<left>= (shift-arrows) on the heading
to cycle TODO → DONE. =C-c C-t= sets the state directly.

** Links
=C-c C-l= inserts a link (to a file, a heading, a URL). =RET= on a link follows
it (this config sets =org-return-follows-link=).

** Emphasis
=*bold*=, =/italic/=, ==code==, =~verbatim~=. Markers are hidden until your
cursor is on the word (org-appear) — that's normal.

** Source blocks
Type =<s= then =TAB= (org-tempo) to expand a =#+begin_src … #+end_src= block.

* Capture — never lose a fleeting idea
:PROPERTIES:
:CUSTOM_ID: capture
:END:

Press =SPC c= (or =C-c c=), pick:
- =i= — Inbox: a quick idea → filed under *Inbox* in =inbox.org=.
- =t= — Task: a TODO → filed under *Tasks*.

Type the note, then =C-c C-c= to save it (or =C-c C-k= to cancel). Your inbox
lives in your =org/= folder (outside this config). Open it with =SPC n i=.

*Exercise:* =SPC c i=, type "try org capture", =C-c C-c=. Then =SPC n i= to see it.

* Tables and glossing
:PROPERTIES:
:CUSTOM_ID: tables
:END:

Start a table by typing a header line with pipes and pressing =TAB=:

: | Form | Gloss | Notes |
: |------+-------+-------|

=TAB= moves to the next cell (creating rows as needed); =|-= then =TAB= draws a
rule. Columns stay pixel-aligned even in the prose font (valign) — good for
interlinear examples. Toggle valign with =M-x valign-mode= if a huge table lags.

* Assembling notes by reference (transclusion)
:PROPERTIES:
:CUSTOM_ID: transclusion
:END:

To pull the live content of another file/heading into the current document, add
a line like:

: #+transclude: [[file:chapter1.org::*Method]]

Then =SPC n t= (=org-transclusion-add=) to render it, or =SPC n T= to toggle the
whole buffer. Edits stay in the source file — great for stitching a thesis from
section files without copy-paste.

* Images
:PROPERTIES:
:CUSTOM_ID: images
:END:

Copy an image to the clipboard, then =SPC n d= (=org-download-clipboard=) to drop
it into the note; the file is saved under =images/= beside your notes. You can
also drag a file from the OS into an Org buffer.

* Reading — feeds
:PROPERTIES:
:CUSTOM_ID: feeds
:END:

=SPC n e= opens elfeed (linguistics feeds — LINGUIST List calls, jobs, journals,
Language Log). =G= refreshes, =RET= reads an entry, =s= filters. Edit the feed
list in the *elfeed* block of =Config.org=.

* Export (later)
:PROPERTIES:
:CUSTOM_ID: export
:END:

Export tooling (Quarto, Typst) is a later pass. For now, =C-c C-e= opens Org's
export dispatcher for the built-in backends.

* Read-aloud & dictation (Linux)
:PROPERTIES:
:CUSTOM_ID: readback
:END:

A review workflow: Emacs reads *continuously from the current paragraph to the
end of the section* (pocket-tts), synthesizing the next paragraphs in the
background so it doesn't pause between them. Any time, pause and *speak a
comment*: it's transcribed (Parakeet v3) and dropped in as an Org =#= comment
under the paragraph being read *at that moment*, then reading resumes where it
paused. Those comments don't export to Word, but you can review them or feed the
file to an LLM. Enable it on an =.org= file with =SPC t R= (or
=M-x e6/readback-mode=); enabling loads the speech models, disabling frees them.

** Controls (while the mode is on)
:PROPERTIES:
:CUSTOM_ID: readback-controls
:END:

| Key         | Action                                                        |
|-------------+---------------------------------------------------------------|
| =<f7>=      | Read from the current paragraph to the end of the section (or the region) |
| =<f8>=      | Dictate a comment: once = *pause + record*, again = *stop + insert + resume* |
| =<f9>=      | Stop reading                                                  |
| =<f6>=      | Switch language English ⇄ Spanish (restarts the voice model) |
| =<f10>=     | Slower                                                        |
| =<f12>=     | Faster                                                        |
| =M-<f12>=   | Reset speed to 1.0×                                           |

*Playback speed* changes take effect immediately on the current reading and are
remembered for the next paragraph (range 0.5×–3.0×, steps of 0.1). The current
speed is shown when you start reading.

*Comments stack:* a second dictated note on the same paragraph is added *below*
the first, not on top of it. Reading a paragraph skips any =#= comments already
under it.

** Tips
:PROPERTIES:
:CUSTOM_ID: readback-tips
:END:

- Keep point in the paragraph you're reviewing; comments anchor to the paragraph
  that was read.
- Spanish uses pocket-tts's =lola= voice via the higher-quality =spanish_24l=
  model; English defaults to =alba=. Change voices in the *Settings* block of
  =Config.org= (=e6/readback-pocket-voice-en/-es=).
- Requires (Linux): =pocket-tts= (via uv), =mpv=, =arecord=, and the Parakeet
  server deps — see the README's "Read-aloud & dictation" section.

* Tools, conversions & services
:PROPERTIES:
:CUSTOM_ID: tools
:END:

=SPC l= opens the launch/convert menu.

- *Convert the current file:* =w= → Word, =h= → HTML, =p= → PDF (all via Quarto,
  which works from Org/Markdown/QMD); =t= compiles a =.typ= with Typst.
- *Services (=SPC l s=, prodigy):* start/stop long-running things and *see what's
  running* — ships with *marimo* (=uvx marimo edit=) and *BentoPDF* (a podman
  container). In the list: =s= start, =S= stop, =r= restart, =b= open its URL.
- *Forgot what you left running?* =SPC l s= shows every service's status, and
  =SPC l P= (=list-processes=) shows all Emacs child processes. Everything you
  launch this way is owned by Emacs, so quitting Emacs stops it too.

*Linting:* open a Markdown/YAML/TOML/Lua/Typst/Rust/Python file and you get
diagnostics automatically *if* the matching language server is installed (see the
README for which and how). Nested brackets are colour-coded by depth in code.

* The config workflow (important)
:PROPERTIES:
:CUSTOM_ID: workflow
:END:

- All settings live in =Config.org=. Open it, edit a block, *save* — it
  auto-tangles to =post-init.el=. Restart Emacs (or re-eval) to apply.
- *Never* hand-edit the =*-init.el= files; they're generated.
- The base (=init.el=, =early-init.el=) is minimal-emacs.d — don't edit those
  either; customise via =Config.org=.
- It's a git repo: =SPC g g= for Magit. Commit as you change things; pull/push
  to sync your other machine.

Happy writing.
