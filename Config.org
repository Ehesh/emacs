This is a *writing-first scholarly environment*, built on [[https://github.com/jamescherti/minimal-emacs.d][minimal-emacs.d]].

* How this config is structured
:PROPERTIES:
:CUSTOM_ID: structure
:END:

minimal-emacs.d gives us two files we *never edit* — =early-init.el= and
=init.el=. They load our own files in a fixed order:

: early-init.el  ->  pre-early-init.el  ->  post-early-init.el
: init.el        ->  pre-init.el  ->  (packages)  ->  post-init.el

Everything in *this* file tangles into =post-init.el= (the last file loaded),
so it runs after minimal-emacs.d's defaults and package setup are in place.

*The golden rule:* edit only this =Config.org=. Never hand-edit the generated
=.el= files — they are overwritten on every tangle. Saving this file
auto-tangles it (see below).

*Portability:* the =:tangle post-init.el= target above is a *relative* path, so
it always resolves next to this file regardless of how Emacs was launched or
which OS you're on. (Absolute =~/.emacs.d/...= targets are fragile on Windows:
=~= only points here when Emacs is launched without =HOME= set, e.g. from the
Start menu, but not from a shell.)

This is the *boot-first minimal slice*: clean, portable, sane defaults, and a
modern-looking theme placeholder. The full look (nano), packages, meow, Org
tooling, etc. layer on in later passes. The previous large config is preserved
in =Config.org.bak= to salvage from.

* Auto-tangle on save
:PROPERTIES:
:CUSTOM_ID: auto-tangle
:END:

Re-tangle =Config.org= automatically whenever it is saved. Implemented with a
plain =after-save-hook= (no external package) so it works on a fresh clone
before anything is installed. Matches by filename, so it is independent of how
=~= or =user-emacs-directory= happen to resolve.

#+begin_src emacs-lisp
(defun e6/auto-tangle-config ()
  "Tangle the Emacs `Config.org' when it is saved."
  (when (and buffer-file-name
             (string-equal (file-name-nondirectory buffer-file-name)
                           "Config.org"))
    (let ((org-confirm-babel-evaluate nil)
          (message-log-max nil)
          (inhibit-message t))
      (require 'org)
      (org-babel-tangle))))

(add-hook 'after-save-hook #'e6/auto-tangle-config)
#+end_src

* Persistence modes
:PROPERTIES:
:CUSTOM_ID: persistence
:END:

minimal-emacs.d configures the *variables* for these but leaves enabling the
*modes* to us. Turn on the ones a scholar wants running everywhere. (Their
state files land in this directory and are gitignored.)

#+begin_src emacs-lisp
;; Remember recently opened files.
(add-hook 'after-init-hook #'recentf-mode)
;; Persist minibuffer history between sessions.
(add-hook 'after-init-hook #'savehist-mode)
;; Reopen files at the last cursor position.
(add-hook 'after-init-hook #'save-place-mode)
;; Keep buffers in sync with files changed on disk (e.g. after a git pull).
(add-hook 'after-init-hook #'global-auto-revert-mode)
#+end_src

* Look & feel
:PROPERTIES:
:CUSTOM_ID: look
:END:

This is *Pass 1: the look* — a genuinely modern, calm, typeset-document feel
(nano aesthetic), not "90s Emacs". It layers, so we keep our own keys and
packages:

- *fontaine* — font presets (FiraCode mono + Gentium prose)
- *nano-theme* — the colour palette
- *nano-modeline* — a minimal modeline
- *spacious-padding* — airy internal borders/padding
- *mixed-pitch* — prose in Gentium, code/tables in FiraCode
- *org-modern* + *org-appear* — Org reads like a document

All installs are handled by minimal-emacs.d's =use-package-always-ensure=.

** Fonts — fontaine
:PROPERTIES:
:CUSTOM_ID: fontaine
:END:

fontaine defines named font presets and applies them to the =default=,
=fixed-pitch=, and =variable-pitch= faces. Missing fonts fall back to the Emacs
default automatically (no error), so this is safe on a machine without them.

#+begin_src emacs-lisp
(use-package fontaine
  :if (display-graphic-p)
  :config
  (setq fontaine-presets
        '((default
           :default-family "FiraCode Nerd Font"
           :default-height 120
           :fixed-pitch-family "FiraCode Nerd Font"
           :variable-pitch-family "Gentium Plus"
           :variable-pitch-height 1.15)))
  ;; Persist and restore the last-used preset across sessions.
  (fontaine-mode 1)
  (fontaine-set-preset (or (fontaine-restore-latest-preset) 'default)))
#+end_src

** Modeline — nano-modeline
:PROPERTIES:
:CUSTOM_ID: modeline
:END:

A minimal modeline. This version installs a modeline *per major mode*, so we
hook the ones we live in. Placed at the bottom (=footer=); switch to
=nano-modeline-header= for the classic nano top bar. Buffers without a hook keep
the default modeline for now (more modes get wired in as those features land).

#+begin_src emacs-lisp
(use-package nano-modeline
  :init
  (setq nano-modeline-position 'nano-modeline-footer)
  :hook
  ((prog-mode . nano-modeline-prog-mode)
   (text-mode . nano-modeline-text-mode)
   (org-mode  . nano-modeline-org-mode)))
#+end_src

** Org appearance — mixed-pitch, org-modern, org-appear
:PROPERTIES:
:CUSTOM_ID: org-look
:END:

The single biggest "reads like a document" win: prose in the variable-pitch
font, code/tables/keywords staying monospaced (=mixed-pitch=); modern headings,
tags, blocks and tables (=org-modern=); and emphasis markers (=*bold*=,
=/italic/=) hidden until the cursor is on them (=org-appear=, which needs
=org-hide-emphasis-markers=).

#+begin_src emacs-lisp
;; Prose gets the variable-pitch font; code/tables stay fixed-pitch.
(use-package mixed-pitch
  :hook ((org-mode  . mixed-pitch-mode)
         (text-mode . mixed-pitch-mode)))

;; Modern Org rendering.
(use-package org-modern
  :config
  (with-eval-after-load 'org
    (global-org-modern-mode)))

;; Reveal emphasis markers only around point.
(use-package org-appear
  :hook (org-mode . org-appear-mode))

(with-eval-after-load 'org
  (setq org-hide-emphasis-markers t
        org-pretty-entities t))
#+end_src

** Cleaner modeline names — diminish
:PROPERTIES:
:CUSTOM_ID: diminish
:END:

Hide noisy minor-mode lighters so the modeline stays calm.

#+begin_src emacs-lisp
(use-package diminish
  :config
  (with-eval-after-load 'which-key  (diminish 'which-key-mode))
  (with-eval-after-load 'mixed-pitch (diminish 'mixed-pitch-mode))
  (with-eval-after-load 'org-appear (diminish 'org-appear-mode))
  (diminish 'visual-line-mode)
  (with-eval-after-load 'autorevert (diminish 'auto-revert-mode)))
#+end_src
